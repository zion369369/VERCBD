1. Executive Summary & System Overview Architecture Scope

The Village Education Resource Center (VERC) web platform is an enterprise-grade digital ecosystem built to serve beneficiaries, donors, humanitarian partners (e.g. UNICEF, Water.org), and administrative stakeholders. The platform delivers high-speed public awareness, dynamic programmatic discovery (WaSH, Non-Formal Education, Health, Microfinance), an AI-assisted conversational interface powered by Google Gemini, and a centralized administrative control center with real-time optimistic state management.

3. Core Operational Flowcharts Execution Paths
Flowchart A: Public Visitor Request & Content Rendering Flow

How visitor requests are routed, resolved, cached, and rendered with sub-second response times:

1
Client HTTP Request

Visitor navigates to a URL (e.g. /programs/wash or /microfinance). Request hits Edge CDN.

2
SSR / Context Resolution

Next.js evaluates server components or initializes ContentContext with cached schema snapshot.

3
Backend API Fallback

Dynamic data is fetched from NestJS backend /programs/:slug backed by PostgreSQL database.

4
Client Hydration & Motion

HTML stream rendered, Framer Motion triggers entry animations, full interactivity active.

Flowchart B: AI Assistant Streaming Query Flow (Server-Sent Events)

The specialized low-latency flow connecting the visitor to the Google Gemini model with domain grounding:

1
User Enters Query

Visitor asks question in Chatbot.tsx (e.g. "What is VERC's CLTS approach and recovery rate?").

2
Proxy to Route Handler

Chatbot dispatches POST to /api/chat with conversation history and user prompt.

3
Gemini API Invocation

Route handler injects system instructions (1977 history, Microfinance KPIs) & calls Gemini 1.5 Flash.

4
SSE Token Streaming

Chunks streamed back via text/event-stream and typed in real-time on screen in under 120ms.

Flowchart C: Admin Content Lifecycle & State Propagation

The administrative publishing workflow with immediate optimistic UI updates and persistent backend storage:

1
Admin Update Action

Editor updates a Hero slide, Program reach metric, or adds a new Story in /admin dashboard.

2
Optimistic State Commit

ContentContext updates in-memory React state instantly, saving to localStorage.

3
Audit Log Generated

System automatically registers an audit trail entry with timestamp, user action, and affected entity.

4
Live Site Synchronized

All connected client components immediately reflect updated content across navigation tabs.

5. Operational Infrastructure & Deployment Blueprint DevOps & Cloud

☁️ Production Cloud Hosting (Render + Netlify)

  • Frontend Web Service: Next.js 14 deployed on high-availability edge nodes with automatic cache invalidation on Git push.
  • Backend Web Service: Containerized NestJS 10 microservice running Node 20 runtime on Render with automated health checks.
  • Database Engine: Managed PostgreSQL 16 instance with connection pooling (DATABASE_URL) and SSL encryption.
  • Declarative IaC: Fully defined via render.yaml Blueprint for one-click environment provisioning.

💻 Local Developer Environment

  • 1-Click Scripts: start-dev.bat / start-dev.sh to launch Frontend (:3000) and Backend (:3001) simultaneously.
  • Local Persistence: Embedded SQLite engine with instant migrations (prisma db push) and automated seed data.
  • Container Option: docker-compose.yml providing isolated PostgreSQL 16 with persistent volume verc_postgres_data.
  • API Exploration: Interactive Swagger UI at http://localhost:3001/api/docs.

6. Security, Governance & Disaster Recovery Enterprise Compliance

🔒 Security & Access Controls

  • CORS Hardening: Backend API restricts origin access to verified frontend domains.
  • Secret Isolation: GEMINI_API_KEY and database credentials stored exclusively in server environment variables, never leaked to client bundles.
  • Input Sanitization: Form inputs and API payloads are validated to prevent SQL injection and XSS.
  • Audit Logging: All administrative modifications (content edits, slide reorders) generate timestamped audit records.

🛡️ Disaster Recovery & Reliability

  • Automated Database Snapshots: Managed daily snapshots with point-in-time recovery (PITR).
  • Decoupled Resilience: If backend API is temporarily unreachable, frontend utilizes client cached data for uninterrupted browsing.
  • Graceful Degradation: AI Assistant detects missing API keys or timeout and serves structured static help links.
  • Data Portability: Complete JSON export / import available inside Admin portal for instant state backup.
